# Bruno Portfolio

Portfólio híbrido (site + currículo imprimível) de **Bruno Sérgio** — desenvolvedor júnior em transição para TI, com foco em backend e mobile.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000). Currículo em `/resume` (use **Imprimir / salvar PDF**).

## Personalizar

Edite `src/data/profile.ts`:

- `links.email` e `links.linkedin`
- textos, projetos e stack

## Stack do site

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
